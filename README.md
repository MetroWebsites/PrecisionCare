## 🔧 Setup & Development

### Local Development

1. Navigate to the project directory:
```bash
cd /home/user/webapp
```

2. Start a local server:
```bash
python3 -m http.server 8000
```

3. Open browser to: `http://localhost:8000`

### File Editing

- **HTML:** Edit `index.html` for content changes
- **Styles:** Edit `css/styles.css` for design updates
- **Scripts:** Edit `js/script.js` for functionality changes
- **Images:** Add/replace files in `images/` folder
